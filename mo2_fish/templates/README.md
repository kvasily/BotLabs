Put native-resolution PNG crops from your own 3840×2160 game image here.
`config.yaml` lists every required filename, including hook/bait variants,
the complete `Taskmaster: Fishing` phrase, fish names, quest UI indicators,
progress `0/3` through `3/3`, empty/zero bait indicators, and logout confirmation.

Crop tightly around distinctive detail. Do not resize. Do not use blank or flat
images. Include all letters in text templates, and use the same text size in the
quest list and tooltip (or enable local OCR when those sizes differ).

`compass_n.png` must match the N glyph around the ring. `tick_*.png` files are
optional, labeled reference patches for the alternative compass mode.
No game artwork is supplied or fabricated.
